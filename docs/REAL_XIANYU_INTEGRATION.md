# 真实闲鱼账号接入选择

## 官方路径

闲鱼开放平台公开资料面向受邀服务商/小程序业务。接入通常需要企业主体、闲鱼业务邀请、淘宝开放平台 AppKey、权限审批和聚石塔部署。公开服务端消息列表主要是订单/退款状态消息，没有面向普通个人卖家的买家私聊收发 API。

如果具备官方资质，本项目可以实现 `OfficialXianyuAdapter`：OAuth/TOP Token、官方消息订阅、账号授权与 Token 刷新都只通过获批接口完成。

所需材料：

- AppKey / AppSecret（只在后台或环境变量中配置，不在聊天中发送）
- 已审批的 API 与消息 Topic 列表
- OAuth 回调地址和授权范围
- 官方联调环境、签名规则与错误码文档

## 非官方个人账号路径

GitHub 可用方案普遍采用：可见浏览器扫码获取 Cookie → 调用网页 MTOP 获取 IM Token → 连接网页端私有 WebSocket → 解析和发送消息。

项目已实现实验性网页版 Adapter，但它不是官方稳定接口，可能随时失效，也可能触发登录验证、限流或账号处罚。默认演示仍使用 Mock 账号。

`ExperimentalWebXianyuAdapter` 的运行边界：

- 只连接用户自己的账号
- 只允许可见浏览器人工扫码
- 验证码/滑块全部由用户本人在官方页面完成
- 不读取现有浏览器 Cookie，不接收手工粘贴 Cookie，不保存账号密码
- Cookie 使用后端加密存储，日志永不输出完整 Cookie/Token
- 连接器运行在独立进程/容器，可一键撤销和清空凭据
- 第一阶段仅接收和发送文本消息
- 每个账号独立限流、退避、熔断和紧急停止
- 商品发布仅在管理员逐件复核并明确确认后执行；不实现批量发布、擦亮、改价、退款或任何风控绕过
- 协议异常或出现验证时立即停止自动发送并转人工

## 当前决定

默认使用 `MockXianyuAdapter`。官方 `RealXianyuAdapter` 仍是未配置的预留骨架。实验性网页版接入已实现，使用者应通过 Windows 专用 Edge 登录助手主动登录自己的账号；Docker 本身不会启动宿主机浏览器，推荐使用根目录 Windows 一键启动脚本。不要将账号凭据、浏览器 Profile 或数据库包含在分享包中。

2026-09-10：按当前用户明确要求，实验性网页版账号新增“真实发布商品”。该能力仅用于用户本人账号，采用图片上传、平台类目识别和单次发布请求；每账号每分钟最多一次，保留审计记录，最终请求不自动重试。超时、验证或风控均停止并要求人工确认结果。批量发布、验证码处理和风控绕过仍不在范围内。
